# Text Runs

Learn any text by heart: the voice says a piece, you say it back.

Open the site in Safari on iPhone, tap Share, then **Add to Home Screen**. It opens full screen, works
offline, and picks up each new version the next time it opens.

- `index.html`: the whole app
- `sw.js`: offline helper
- `manifest.webmanifest` and `icons/`: home-screen name and icon
- `pdfjs/`: PDF reader for importing PDFs (pdf.js, Apache 2.0 license)

Your texts are stored on your phone, not on this site.
